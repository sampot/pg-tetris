# pg-tetris

瀏覽器**俄羅斯方塊輕量版**：七種方塊、七袋隨機、消行升級、幽靈影、觸控按鍵。純前端；**mobile-first**。

名稱與手感致敬方塊類遊戲，非任一商業作品復刻。

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。

## 一鍵開 SAM

```
https://play.samkuo.me/?open=sampot/pg-tetris&name=俄羅斯方塊&fresh=1
```

## 試玩（本機）

```bash
npx --yes serve .
```

## 操作

| 操作 | 說明 |
| --- | --- |
| ← →／按鍵 | 左右移動 |
| ↑／↻／X | 旋轉 |
| ↓ | 軟降 |
| 空白／硬降 | 瞬降鎖定 |
| P／暫停 | 暫停／繼續 |
